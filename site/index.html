Chrome and Brave profiles

Give GitHub a key in your work Chrome or Brave profile. CapsJump brings a matching tab forward when it can find one. If no tab matches, it opens the page in that profile.

Apps

Caps + S and your terminal is just there. Not running? It starts. Hiding with no window? It opens one. No more fishing in the Dock.

Windows

Caps + an arrow sends the front window to that half of the screen: ← → ↑ ↓. Caps + F and it goes big. Rather other keys? Press the one you want, or turn any off.

Links

Caps + W drops you into a Slack channel, a Zoom room or any web page, in the app that owns the link. Bookmarks, but with legs.

See it

Rather click than write YAML? Pick Edit Config… in the menu bar and every key and site is right there.

One file, ~/.capsjump.yaml

Each key does one thing, and the window above saves straight to this file, checked by the same rules as you type. Prefer a text editor? Open Config File, and the file looks like this:

sites:
- name: github
  account: you@work.com
  open: https://github.com/your-org/your-repo/pulls

keys:
  s: {app: iTerm}
  t: {app: Finder}
  g: {site: github}
  left: {window: left-half}
  right: {window: right-half}
  up: {window: top-half}
  down: {window: bottom-half}
  f: {window: maximize}
  w: {url: 'slack://channel?team=T123&id=C456'}

Key names: a–z, 0–9, f1–f12 and the arrows. A file with no keys: leaves Caps Lock as it is.

Unzip it, move CapsJump.app to Applications, and open it.

Homebrew

brew install --cask whysosuresh/tap/capsjump

Open source. CapsJump has no analytics. Quit CapsJump and Caps Lock works normally again.

Accessibility lets CapsJump handle your shortcuts and move windows. Access to Chrome or Brave lets it find and switch tabs. Configuration and saved icons are read locally; websites and apps you open make their own connections.

Set up your keys

Both routes open the same Welcome window, with three steps that tick themselves as you go:

  1. Let CapsJump hear Caps Lock. macOS asks with its own box: click Open System Settings there and turn CapsJump on. The step ticks the moment you do.
  2. Choose your keys. One click turns on the starter keys (the arrows snap the front window to a half, F fills the screen), or set up your own. While CapsJump has keys, Caps Lock no longer types capitals; Shift still does.
  3. Try it. Click any window, hold Caps Lock and press ←.

Notifications and Start at login have their own controls in the Welcome window. Close it whenever you like: CapsJump's mark in the menu bar carries a small dot until it's set up, and its menu starts with Finish Setting Up….

Give GitHub a key

G is an example you configure; the starter keys move windows.

  1. In the Welcome window, choose Allow… under Chrome accounts. If access was previously denied, choose Open Automation Settings instead. For Brave, macOS asks the first time CapsJump reads one of its tabs.
  2. Open GitHub in the Chrome or Brave profile you want, then choose Add Current Tab… from CapsJump's menu.
  3. When the Account field is shown, confirm the intended profile; select it if it says Choose…. Assign G or another available key, then choose Add or Add Key.
  4. Hold Caps Lock and press the key you assigned.

Good to know

  • Chrome and Brave, for sites. Site keys work with Google Chrome and Brave profiles; app, window and link keys work with any app. A site's account picks its browser: a name only Brave has lands in Brave; an email, or a name both browsers have, lands in Chrome. So if you use both, give your profiles different names.
  • Profiles and open tabs. CapsJump chooses the browser profile, not the account signed in on a website. Tabs on other desktops or in full-screen windows may open again. Profiles with the same window label open a new tab instead of reusing one.
  • Site icons and account pictures come from your browser. Each site shows the icon its browser has already saved on your Mac for that account, and each account the picture the browser shows for it. Nothing is fetched; a site the browser hasn't shown there yet keeps a globe.
  • Windows stay on their screen. A window snaps within the screen it is on; moving it to another screen isn't a key yet.
  • Not while typing a password. macOS keeps every app's shortcuts out of password fields; the keys work again as soon as you leave one.
  • Miss SHOUTING? Hold Shift, like everyone else. Or pause or quit CapsJump from its icon in the menu bar, and Caps Lock goes back to its old job at once.
